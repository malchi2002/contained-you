# Contain:You — video drops

Every video for **Contain:You** lands here first, then goes out through Metricool
(brand **Contain:You** → Instagram @containedyou + YouTube).

## Pipeline
1. Add a folder `drops/NNN-subject/` (copy `drops/_template/`).
2. Put in it: `video.mp4` (1080x1920, 72–75 s, < 100 MB), `cover.jpg`, and fill `post.md`.
3. Push to `main`. The repo is public, so the raw URL
   `https://raw.githubusercontent.com/malchi2002/contained-you/main/drops/NNN-subject/video.mp4`
   is what Metricool pulls as the media.
4. Schedule in Metricool: Instagram **Reel** + YouTube **Short**, caption from `post.md`.

## Drop checklist (from the RedScarfLives breakdown)
- 72–75 s, 1080x1920, 30 fps
- 2-line hook in the first 4 s (line 1 white = situation, line 2 red/orange = twist)
- Title card, then 6–8 beats of ~7 s: chapter tag top-left + one HUD counter that ticks each beat
- Dark low-key pixel art (~half the frame near-black), one warm light, dithered gradients
- White-flash at act breaks, slow drift between them
- **The lantern is hidden in every video**
- Stat card, then CTA: "Who do you respawn as / next?"
